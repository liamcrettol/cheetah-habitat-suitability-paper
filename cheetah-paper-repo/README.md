# Landscape Fragmentation and Conservation Strategies for Cheetahs in Northern South Africa

This repository contains the LaTeX manuscript and supporting figures for a paper on cheetah conservation in northern South Africa, with a focus on landscape fragmentation, habitat suitability, monitoring methods, and minimum viable population context.

## Repository structure

- `manuscript/main.tex` — main LaTeX manuscript
- `figures/study_region_map.png` — study area map
- `figures/vegetation_classification_map.png` — vegetation classification map

## Notes

The manuscript uses an inline bibliography in `main.tex`, so no separate `.bib` file is required for compilation in its current form.

## Suggested workflow

Clone the repository, compile `manuscript/main.tex`, make edits locally, then commit and push changes back to GitHub.
